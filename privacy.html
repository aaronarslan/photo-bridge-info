Privacy Policy

This policy describes Drive Photos Bridge, a private Google Apps Script automation operated by its owner for that owner's Google Account.

Information accessed

The bridge checks the authorized Google Account's email address to ensure it is the configured owner. It reads file and folder identifiers, names, types, sizes, checksums, parent folders, modification times and download availability to find new media in the configured source folder and its descendants. It downloads those media files through Google's APIs and uploads their original bytes to the owner's Google Photos library.

The Google Drive read permission can view and download account files broadly. The added Drive metadata permission can view and change file information across the account, including moving files to recoverable Trash; it does not grant permission to change file contents or permanently delete files. The implementation limits media transfer and source cleanup to the configured source folder and its descendants and does not follow shortcuts outside that folder. The Google Photos permissions allow adding media and reading only media created by this app, so the bridge can verify an imported copy and wait for a video to finish processing. They do not permit deleting Google Photos items or reading the rest of the owner's Photos library.

Information stored

A private app-data file in the owner's Google Drive records file versions, completed imports, Google Photos item identifiers and links, capture times, progress, skipped items, cleanup queues and outcomes, errors and usage accounting. Explicitly verified equivalent file checksums can link source copies to an existing import to preserve corrected capture dates without duplicate uploads. Temporary upload session details and upload tokens support resuming interrupted transfers. Google Apps Script properties store configuration and schedule state. Google manages the account authorization used by Apps Script.

Execution logs in Google Apps Script may contain file names, item links, capture times and errors. These records are accessible through the owner's Google project and are subject to Google's logging retention and account controls. Progress history is retained until the owner removes it; it is used to avoid importing a completed file version again.

Use and sharing

Information is used to transfer selected media, verify the authorized account, resume uploads, avoid duplicate processing and diagnose failures. The bridge's media transfer and progress storage use Google's services. The bridge does not sell data, use it for advertising, train artificial intelligence models on it, or send media to the website host.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Owner choices and deletion

The owner can pause the scheduled job in Google Apps Script and revoke the app's access in Google Account connections. When enabled by the owner, source cleanup moves an unchanged source file to recoverable Google Drive Trash only after its saved Google Photos import has been verified. Videos remain in the source until Google Photos reports READY. A file that changed, moved outside the selected source or failed verification is retained. No automatic permanent deletion or emptying Trash is performed. Google normally permanently removes Drive Trash after 30 days; trashed items count toward Google storage until permanently removed. Drive deletions may sync to the owner's computer. The owner controls deletion of imported Photos media, private progress records and the script project. Revoking access or pausing imports does not delete existing media from either service. Copies in Drive and Photos are managed separately.

This information website

The static website has no media upload, Google authorization, analytics or tracking code. Its hosting provider, GitHub Pages, may process ordinary web request information under the GitHub Privacy Statement. Media and private bridge progress records are not published on this website.

Contact and changes

Questions can be directed to the owner's support email displayed on the Google authorization screen. The date above will change if this policy is updated.
